## Header Bar

### Workspace Switcher
If multi-workspace is enabled, click the workspace dropdown to switch between workspaces.

### Notifications (🔔)
- Click to view recent notifications
- Badge shows unread count
- Configure notification preferences in Settings

### Global Search (⌘K)
- Search across all entities (controls, risks, vendors, etc.)
- Press `⌘K` (Mac) or `Ctrl+K` (Windows) to open
- Type to search, arrow keys to navigate, Enter to select

### Account Menu
- **Account Settings**: Profile, preferences
- **Help Center**: Documentation and guides
- **Sign Out**: End your session

## Keyboard Shortcuts

Press `⌘/` (Mac) or `Ctrl+/` (Windows) to see all shortcuts:

| Shortcut | Action |
|----------|--------|
| `⌘K` | Open global search |
| `⌘/` | Show keyboard shortcuts |
| `⌘N` | Create new item (context-dependent) |
| `Escape` | Close modal/dialog |
| `↑↓` | Navigate lists |
| `Enter` | Select/open item |

## Page Layouts

### List Pages
Most list pages (Controls, Risks, Vendors) have:
- **Search Bar**: Filter by text
- **Filters**: Category, status, date range
- **Sort**: Column headers are clickable
- **Actions**: Add, Export, Bulk Upload
- **Pagination**: Navigate large lists

### Detail Pages
Detail pages for individual items show:
- **Header**: Title, ID, status badge
- **Actions**: Edit, Delete, more options
- **Tabs**: Different sections of information
- **Related Items**: Linked entities
- **Activity**: History and changes

### Settings Pages
Settings are organized by category:
- **Cards**: Each setting group in a card
- **Forms**: Input fields with descriptions
- **Save Buttons**: Per-section saving

## Mobile Navigation

On smaller screens:
- Sidebar collapses to hamburger menu (☰)
- Touch-friendly buttons and spacing
- Swipe gestures for navigation

## Tips

1. **Collapse Sidebar**: Click the hamburger icon to maximize content area
2. **Right-Click Context Menus**: Many items have context menus
3. **Breadcrumbs**: Use breadcrumbs at the top to go back
4. **Recent Items**: Dashboard shows your recently viewed items

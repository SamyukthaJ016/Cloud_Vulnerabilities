Quick Setup - Automated Role Creation

Deploy a CloudFormation stack to automatically create a read-only IAM role with all necessary permissions. This is the recommendedand safestway to set up CloudGuard scanning.

Launch CloudFormation Stack

Click the button below to open AWS CloudFormation console with pre-configured template

2
Review & Create

Ensure ScannerAccountIdmatches your ID, check the IAM acknowledgment box, and create the stack

3
Copy Role ARN

After stack creation, copy the Role ARN from the Outputs tab

4
Complete Setup
